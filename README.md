# 라이츠 아웃 💡

칸을 눌러 모든 불을 끄는 퍼즐. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나. 의존성 없는 정적 게임(`index.html` + `logic.js` + `levels.js` + `game.js`)입니다.

- n x n 칸에 불이 켜진 칸과 꺼진 칸이 있다. 칸을 누르면 그 칸과 **위·아래·왼쪽·오른쪽** 칸의 불이 모두 반대로 바뀐다. 불을 모두 끄면 클리어
- 같은 칸을 두 번 누르면 원래대로 돌아온다. 그래서 풀이는 "어느 칸들을 한 번씩 누를까"의 문제이고, 눌러 보는 순서는 상관없다
- 30단계: 3x3 다섯 개, 4x4 열 개, 5x5 열다섯 개. 아무 단계나 골라서 할 수 있다 (☰)
- ↩ 되돌리기(Z) 무제한, 🔄 다시(R), 💡 힌트(H): 지금 판에서 **가장 적게 누르는 풀이** 중 한 칸을 분홍 테두리로 알려 준다 (중간에 다른 칸을 눌러도 그 시점에서 다시 계산)
- ⭐ 별: 최소 누르기 수(par)로 풀면 3개, 그 1.5배+1 안이면 2개, 그보다 많으면 1개. **힌트를 쓰면 최대 2개**. 단계마다 가장 좋은 기록을 저장한다 (`lightsoutDone`), 로비에는 깬 단계 수(`lightsoutCleared`)가 보인다
- 판은 모두 풀 수 있다: 누를 칸들을 무작위로 골라 꺼진 판에 눌러서 만들고(`tools/generate.js`), **GF(2) 연립방정식**(`logic.js` 의 `solve`)으로 풀어 가장 적게 누르는 횟수를 쟀다. 5x5 판은 4분의 1만 풀 수 있고(풀이가 4가지씩 있어서 그중 가장 적은 것을 par 로 쓴다), 4x4 는 최대 7, 5x5 는 최대 15번이면 풀린다. 3x3 은 풀이가 하나뿐이다

규칙과 풀이는 `logic.js`(화면 없이 Node 로 시험할 수 있다), 레벨은 `levels.js`, 화면·입력·소리는 `game.js`. 시험은 `node --test` (`test/logic.test.js` 규칙·풀이(3x3·4x4 는 모든 경우를 직접 눌러 보며 대조), `test/levels.test.js` 30단계가 풀 수 있고 par 와 같은지).

## 레벨 다시 만들기
```bash
node tools/generate.js        # 씨앗을 바꾸려면 숫자를 하나 더 (levels.js 를 새로 쓴다)
```
